# OSD-XMB-ART_renamer

English

Python file to create ART for OSD-XMB
Select ART folder from OPL were you have the background and disc PNG file.
Select OSDXMB folder python file will create ART folder if not exist.
User must have Python installed in PC.
Download here: https://www.python.org/downloads/
